# Movie-score-prediction
Project inculdes an implementation of the recommendation system for movie ratings using various algorithms such as NMF, SVD, iterated SVD and SGD. All of these methods will be described in the report. The models based on these methods will be presented with the achieved results.

Data with the movie ratings was downloaded from *https://grouplens.org/datasets/movielens/*. I used only the file *ratings.csv* from *ml-latest-small.zip*. That file contains approximately 100,000 ratings – about 600 users have rated around 9,000 movies.
